
# 澳门六合/特码预测数据多源采集器

轻量级 Python 自动化采集脚本，用于定时同步澳门特码 30 年跨期多算法（周公解梦、奇门遁甲、白小姐玄机等）推演数据。

## 特性

- **免鉴权直出**：无需 API Key 或验证码，原生兼容标准 HTTP 协议。
- **双通道采集**：
  - `/today`：自动解析当日开奖先锋号码与 20 码防爆大底。
  - `/rss.xml`：聚合 8 大算号门派的结构化 XML 订阅流，适配各类 Bot 定时调度。
- **高可用边缘分发**：依托 Cloudflare CDN 边缘节点，延迟低、无并发锁定。

## 快速开始

### 依赖环境

```bash
pip install requests

```

### 运行采集

```bash
python main.py

```

## 数据接口说明

| 接口路由 | 数据类型 | 说明 |
| --- | --- | --- |
| `/today` | HTML / 302 重定向 | 自动定位当日最新特码详情页 |
| `/rss.xml` | XML (RSS 2.0) | 当日全算法频道的聚合数据流 |
| `/sitemap.xml` | XML | 历史与未来推演索引总图 |
